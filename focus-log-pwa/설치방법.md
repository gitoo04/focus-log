# 집중기록 웹앱 설치 방법

## 1. 준비물

- GitHub 계정
- 이 폴더 안의 완성 파일 전체
- 아이폰 Safari

별도 프로그램 설치 없이 GitHub 웹사이트만으로 배포할 수 있습니다.

## 2. GitHub에 새 저장소 만들기

[크롬 주소창에 입력]

```text
https://github.com/new
```

1. GitHub에 로그인합니다.
2. **Repository name**에 `focus-log`를 입력합니다.
3. 공개 범위는 **Public**을 선택합니다. 무료 GitHub Pages에서 가장 간단한 설정입니다.
4. `Add a README file`, `.gitignore`, `license`는 선택하지 않아도 됩니다.
5. **Create repository** 버튼을 누릅니다.

## 3. 완성 파일 업로드하기

1. 새 저장소 화면에서 **uploading an existing file**을 누릅니다.
2. 이 앱 폴더의 다음 항목을 모두 끌어다 놓습니다.
   - `index.html`
   - `styles.css`
   - `app.js`
   - `manifest.webmanifest`
   - `sw.js`
   - `README.md`
   - `설치방법.md`
   - `icons` 폴더 전체
3. 화면 아래 **Commit changes**를 누릅니다.

중요: `icons` 폴더가 빠지면 아이폰 홈 화면 아이콘과 오프라인 설치가 제대로 동작하지 않을 수 있습니다.

## 4. GitHub Pages 켜기

저장소 주소가 `https://github.com/내아이디/focus-log`라면 설정 주소는 아래 형식입니다.

[크롬 주소창에 입력]

```text
https://github.com/내아이디/focus-log/settings/pages
```

위 주소에서 `내아이디`를 본인의 GitHub 사용자 이름으로 바꿉니다.

1. **Build and deployment** 아래 **Source**를 `Deploy from a branch`로 선택합니다.
2. **Branch**를 `main`, 폴더를 `/(root)`로 선택합니다.
3. **Save**를 누릅니다.
4. 보통 1~5분 후 같은 화면에 공개 주소가 표시됩니다.

완성된 앱 주소는 아래 형식입니다.

[크롬 주소창에 입력]

```text
https://내아이디.github.io/focus-log/
```

위 주소에서도 `내아이디`를 본인의 GitHub 사용자 이름으로 바꿉니다. 처음 열 때 404 화면이 보이면 2~5분 기다린 뒤 새로고침하세요.

## 5. 아이폰 홈 화면에 추가하기

1. 아이폰에서 **Safari**를 엽니다. Chrome이 아니라 Safari에서 진행하는 것이 가장 확실합니다.
2. Safari 주소창에 배포된 전체 주소를 입력합니다.

```text
https://내아이디.github.io/focus-log/
```

3. 앱 화면이 열리면 Safari 아래쪽의 **공유** 버튼(위쪽 화살표가 있는 네모)을 누릅니다.
4. 메뉴를 아래로 내려 **홈 화면에 추가**를 누릅니다.
5. 이름이 `집중기록`인지 확인하고 오른쪽 위 **추가**를 누릅니다.
6. 홈 화면의 `집중기록` 아이콘을 눌러 실행합니다.

홈 화면에서 실행하면 Safari 주소창 없이 독립 앱처럼 열립니다. 한 번 온라인에서 실행한 뒤에는 네트워크가 잠시 없어도 기본 화면을 열 수 있습니다.

## 6. 사용 방법

1. 필요하면 `무엇에 집중하나요?` 칸에 메모를 씁니다.
2. **집중 시작**을 누릅니다.
3. 집중이 흐트러진 순간 **집중 깨짐**을 누릅니다. 방금 구간이 저장되고 같은 메모로 새 구간이 즉시 시작됩니다.
4. 일을 마쳤다면 **종료**를 누릅니다.
5. 아래쪽 날짜를 눌러 다른 날의 기록도 확인할 수 있습니다.

## 7. 주의 사항

- 기록은 아이폰의 해당 웹앱/Safari 안에만 저장됩니다.
- Safari의 방문 기록 및 웹사이트 데이터를 삭제하거나 홈 화면 앱 데이터를 지우면 기록이 사라질 수 있습니다.
- 개인 기록이므로 다른 기기와 자동 동기화되지 않습니다.
- 코드 파일을 수정해 다시 업로드했다면 서비스 워커 캐시 때문에 이전 화면이 잠시 보일 수 있습니다. 앱을 완전히 닫고 다시 열거나 Safari에서 새로고침하세요.
